## §2. What shipped

**v0.54.0** — a real product defect. `waitlists.offerExpired` parsed the zone-less SQLite datetime
that `nextOfferExpiry` itself writes, reading a UTC instant as local time. Cloudflare runs UTC so
the offset was zero in production and it stayed invisible; on a UTC-6 runtime a 48-hour claim link
lived 54. Fixed with the normalise-then-parse idiom already in five other modules, plus the
write→read round-trip test that never existed. Also: `preflight.mjs` (the local CI gate + origin
sync check), and the ZIP retired across all four documents that restated it.

**v0.55.0** — `build-status.js` v1.1. The tester-facing registry had gone stale and two entries were
flatly wrong (the door "refuses" an unwaivered member — a gate removed in v0.33.1 on the owner's
instruction). 16 of 45 pages were unregistered. Four shipped features still said "soon". Plus the CI
syntax gate, which **could not fail** and now self-tests.

**v0.56.0** — the admin ✉ badge (`GET /api/admin/messages/flags/count`, parked since v0.48.0),
counting through the same predicate as the queue so the two can never disagree. Cache-buster swept.
Three more stale claims struck.

Full detail is in `CHANGELOG.md`; it is not duplicated here.

## §3. Five defects this session that all reported clean

Recorded together because they are one pattern, and the pattern is the useful artefact:

1. **Five negative controls could not fail on Windows.** `core.autocrlf` meant NCs mutating on a
   literal `\n` silently no-opped — the guard had nothing to detect and passed.
2. **The CI syntax gate could not fail.** `node --check <file>` exits 0 on any ESM file with a
   syntax error (Node 22 *and* 24). All 37 modules are ESM. It had passed unconditionally since
   v0.2.x.
3. **`mailBadgeFill` was defined and never called** — caught only by asking the question directly.
4. **v0.55.0 shipped without a buster sweep**, so the corrected tester copy would not have reached
   a cached browser. The buster guard checks *one* value, not the *current* value.
5. **The documents were wrong about shipped code three releases running, always in the same
   direction** — claiming things unbuilt that had shipped.

Every one of these was green on every existing check. What found them was running the thing and
looking at the output, not reading a document. Weight that accordingly next session.
