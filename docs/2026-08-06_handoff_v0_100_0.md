### §0a-i. How this was found — the check that could not fail

**Re-tested the blocker rather than routing around it** (last session's own rule, applied to a new
claim). The status page said `Actions: major_outage`, but *"the platform is degraded"* and *"my run
cannot start"* are different claims, and only the second one matters — **the status page cannot
speak to the second.** Splitting them is what produced the deploy: a re-run was accepted and
reached `queued` (already better than iteration 18's two hard failures), and a `workflow_dispatch`
then found a runner outright. **Both were free to try and neither was implied by the status page.**

**THE REAL FIND — the static app WAS two releases behind, and the check that should have caught it
could not fail.** When this session opened, `https://10xequity.github.io/btplatform/web/` served
**`?v=0.98.0`** against a repo at `0.100.0`. (Both are current now — §0a. The finding is the blind
spot, not the drift, and the blind spot is what got fixed.)

| Release | Worker (`deploy-worker.yml`) | Static app (`pages-build-deployment`) |
|---|---|---|
| v0.98.0 | green | **green — this is what browsers still run** |

So **v0.99.0's W-F work — the `event` segment filter, the picker, "Email these registrants" — went

v0.99.0 and the ledger recorded it verified. The API moved; the bundle did not. **That is the part
to keep: the ledger entry was not lying, it was reporting a true fact about the wrong half.**

**Why nothing caught it, and this is the reusable part:** the ship has **two halves on two
pipelines**. `deploy-worker.yml` ships `worker/**` to Cloudflare and asserts `/api/health`
afterwards. The static app is shipped by a GitHub-managed `pages-build-deployment` run this repo
does not own, does not gate, and cannot see. `/api/health` proves the **worker** and nothing else —
and the release ritual's Pages step fetched `https://10xequity.github.io/btplatform/` **(the repo
root)**, a redirect stub last edited 2026-07-22 that carries **no `?v=` buster at all** and returns
a byte-identical 200 whether Pages built today or never. **Failure class 3, exactly: a guard
narrower than its subject, reporting clean.** Verified, not assumed — `grep -c '?v=' index.html`
is 0, and `git log` shows the file untouched for two weeks.

**Fixed this iteration:** `preflight` grew a **`pages`** check (reads `/web/`, compares the live

`RALPH.md` PHASE 3 step 7 now names `/web/` and says why. `preflight` currently reports it, which
is the check earning its keep on the first run.
