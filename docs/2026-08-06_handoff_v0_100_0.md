cannot tell a broken feature from a broken fixture and reasonably assume the feature. Each shape
below is real, and each left a code path the seed could never reach:

- **A contact with NO email.** The "Emails of Teammates" cell is free text and rarely holds one

  250; **no seeded team occupied the 350 rung**, so no seeded comparison could span two tiers.

- **A team name containing a comma** — `Jarvis, Jork It A Lil`, real, and the shape that breaks a
  naive CSV split. Same class as the apostrophe in `Spike Lee's` that `q()` exists for.
