**(a) The member sidebar advertised the admin shell.** `site-nav.js` v2.15 pushed a `Manage` group

entry. A bounce off an admin page therefore left `[..., admin.html, home.html]` on the stack —
press Back, the browser re-enters `admin.html`, **repaints the entire static admin shell** (that
page ships its rail and every module name as markup, so it is on screen before `/api/me` can
answer), and `guard()` bounces forward again. **Back never escapes and the shell is re-exposed on
every attempt.** `guard()`'s four rejection paths now use `location.replace`. Deliberate user
navigations — "View as member", the two `history.back()` helpers — still push, because a user's own
click belongs in their history.

source: re-adding an admin href to the real NAV, adding `tournament.html` (which needs its own arm
