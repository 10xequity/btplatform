## §3. The pattern this session kept finding

**Four separate defects, all of which reported clean, and all the same shape: the thing existed and
the path to reaching it did not.**

1. **The rail went dark on `admin-event.html`** — the page where a tournament is built. Not a nav
   destination, so exact-match highlighting found nothing. Owner noticed; `admin-consent.html` had
   the identical hole and nobody had. *Guarded:* `nav_highlight.test.mjs`.
2. **The test fixture could not reach the feature it existed to test.** The upcoming tournament had
   registrations and zero teams, so no pool could be built and the drag editor looked broken. It
   was fine. *Guarded:* `sandbox_seed.test.mjs` asserts the seed sits at the workflow, not that
   rows exist — counting rows passed on the broken set.
3. **Captain self-scoring was `stage='pool'` only**, so bracket games were invisible to the teams
   playing them and the link died when the desk was busiest.
4. **The QR code never worked.** A CDN script with a "library blocked" fallback message. Replaced
   with local code — which then turned out to have two bugs of its own, both producing symbols that
   rendered perfectly and could not be read.

Also: **five pages had accumulated stray `</main>` tags** (v0.66.0) because each new page is sliced
off an old one and inherits the previous mistake plus one; browsers discard the tag silently. And
**the cache-buster sweep had never covered `.js`**.

The common thread is that none of these could fail a test that was looking at the right thing,
because no test was. Measurement found all of them; documents found none.
