# Install v0.14.0 — M12.5 Member Portal & Agreements + M13 Security & Recovery
**File:** 2026-07-24_module13-12-5-install_v0.14.0.md · **Version:** v0.14.0 · **Date:** 2026-07-24

## What this release does
1. **Member dashboard (My Dashboard / home.html):** waiver-status chips for you and each child; an **Agreements** card showing everything ever signed on the account (who it's for, who signed, when, expiry); a **Request court time** card that stays **hidden** until you flip `RENTALS_ENABLED: true` in `web/assets/config.js`.
2. **Security & Recovery (new admin page, People group):** full security log (sign-ins, deletes, money, facility, roles — searchable), **Trash & restore** (bring back deleted events/teams/registrations/members/bookings/rental requests with one click), and **Lockout rescue** (issue a member a fresh one-time sign-in link when they're locked out).
3. No database changes in this release.
