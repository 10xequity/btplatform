Build status

This platform is being built one module at a time, so at any moment some screens are finished and some are not. Read this page before you start testing.

Anywhere a screen is not finished you will also see a small marker on the menu item and a one-line notice at the top of that page, so you do not have to remember this list. Under construction items ask you to confirm before they open — that is deliberate.

Please do file anything wrong on a finished screen, anything confusing, and any wording that reads badly. Please don't file the caveats already listed below — they are known and scheduled.
