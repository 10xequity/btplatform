Calendar feeds

A feed URL is a live subscription: whatever you publish shows up in Google Calendar, Apple Calendar or Outlook within the hour, and cancelled events turn into cancellations rather than vanishing. The link is a password — anyone holding it sees the calendar, so treat it like one and create a new one if it leaks.

Member feeds

Each member gets their own link covering only what they are rostered on. They create it themselves from their profile — staff cannot retrieve someone else's, by design.

Time zone

Event times are stored as wall-clock — "6:00 PM" means 6:00 PM at the facility. This tells calendar clients which wall clock that is. Get it wrong and every subscribed event lands hours off.
